# 📚 Moobi Reader

一款现代化的电子书阅读器 Web 应用，支持 EPUB 和 PDF 格式，采用 iOS 风格设计。

![Moobi Reader](https://img.shields.io/badge/Version-2.0.0-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ 特性

### 📖 文件格式支持
- ✅ **EPUB** - 完整支持 EPUB 格式电子书
- ✅ **PDF** - 支持 PDF 文件阅读（Mac Retina 优化）

### 🎨 设计特色
- 💎 **毛玻璃效果** (Glassmorphism) - 现代化的透明玻璃设计
- 🔵 **大量圆角** - 符合 iOS 设计规范的圆润外观
- 🌈 **动态渐变背景** - 流畅的动画效果
- 🎭 **多主题支持** - 深色、浅色、护眼三种主题

### 📚 核心功能

#### 书架管理
- 📚 **阅读历史**: 自动保存最近阅读的 10 本书
- 📊 **进度追踪**: 实时记录阅读进度和页码
- 🕐 **最近阅读**: 欢迎页面显示最近阅读列表
- 💾 **本地存储**: 所有数据本地保存，隐私安全

#### 书签系统
- 🔖 **快速标记**: 一键添加当前页为书签
- 📍 **精确定位**: EPUB 支持 CFI 精确定位
- 🗑️ **灵活管理**: 查看、跳转和删除书签
- ⌨️ **快捷键**: 按 `B` 键快速添加书签

#### 阅读统计
- ⏱️ **阅读时间**: 实时追踪本次和累计阅读时间
- 📈 **进度分析**: 显示阅读进度百分比
- 📄 **页数统计**: 记录已阅读页数
- 📊 **可视化面板**: 清晰的统计数据展示

#### 全文搜索
- 🔍 **EPUB 搜索**: 在 EPUB 书籍中搜索关键词
- 🎯 **高亮显示**: 搜索结果高亮显示匹配内容
- 📝 **上下文预览**: 显示匹配文本的上下文
- ⚡ **快速跳转**: 点击结果直接跳转到对应位置

#### 目录导航
- 📑 **交互式目录**: 支持 EPUB 目录导航
- 🌳 **层级显示**: 清晰的目录层级结构
- 🎯 **一键跳转**: 点击章节快速跳转
- 💫 **优雅动画**: 流畅的页面切换

#### 阅读设置
- 📝 **字体调节**: 12px - 28px 字体大小
- 📏 **行间距**: 1.2 - 2.2 倍行间距
- 🎨 **三种主题**: 深色、浅色、护眼模式
- 🔄 **实时预览**: 设置即时生效

#### 交互体验
- ⌨️ **键盘快捷键**: 完整的快捷键支持
- 🎯 **拖拽上传**: 支持文件拖拽上传
- 💬 **Toast 提示**: 优雅的操作反馈
- 📱 **响应式设计**: 完美适配各种屏幕

## 🚀 快速开始

### ⚠️ 重要提示

**必须使用本地 HTTP 服务器运行，不能直接双击打开 index.html！**
由于浏览器的 CORS 安全策略，EPUB 文件需要通过 HTTP 服务器加载。

### 方法一：使用启动脚本（推荐）

1. **下载项目**
   ```bash
   git clone <repository-url>
   cd moobi-reader
   ```

2. **运行启动脚本**

   **Mac/Linux:**
   ```bash
   ./start-server.sh
   ```

   **Windows:**
   ```bash
   start-server.bat
   ```

3. **打开浏览器**
   - 在浏览器中访问：`http://localhost:8000`
   - 点击"选择文件"按钮
   - 选择 EPUB 或 PDF 文件
   - 享受阅读！

### 方法二：手动启动服务器

使用以下任一命令启动本地服务器：

```bash
# 使用 Python 3 (推荐)
python3 -m http.server 8000

# 使用 Python 2
python -m SimpleHTTPServer 8000

# 使用 Node.js
npx http-server -p 8000

# 使用 PHP
php -S localhost:8000
```

然后在浏览器中打开 `http://localhost:8000`

## 🎮 使用说明

### 上传文件
**方式 1: 点击上传**
1. 在欢迎界面点击"选择文件"按钮
2. 选择 `.epub` 或 `.pdf` 格式的文件
3. 文件将自动加载并显示

**方式 2: 拖拽上传**
1. 直接将 EPUB 或 PDF 文件拖到浏览器窗口
2. 文件会自动加载

### 导航控制
- **翻页**: 使用底部的左右箭头按钮，或键盘 `←` `→` 键
- **跳转**: 拖动进度条到指定位置
- **目录**: 点击顶部目录按钮查看章节（EPUB）

### 功能面板

#### 📑 目录 (T)
- 查看书籍章节结构
- 点击章节快速跳转
- 仅 EPUB 格式支持

#### 🔖 书签 (B)
- 点击"添加当前页为书签"保存位置
- 点击书签项快速跳转
- 滑动显示删除按钮

#### 🔍 搜索 (F)
- 输入关键词搜索内容
- 查看匹配结果和上下文
- 点击结果跳转到对应位置
- 仅 EPUB 格式支持

#### 📊 统计
- 查看阅读进度
- 本次阅读时间
- 累计阅读时间
- 已读页数

#### ⚙️ 设置 (S)
- 调整字体大小
- 切换主题
- 调整行间距
